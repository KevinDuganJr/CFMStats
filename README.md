# CFMStats — Demo

CFMStats is an online tool for Madden leagues to create and manage their league stats and visualizations. Create your league and view live dashboards at https://cfmstats.com.

Live demo: https://cfmstats.com

Screenshots
- Add screenshot images to the `assets/` directory and reference them below.

Features
- Clean charts and dashboards for Madden leagues
- Free to use (no charge)
- Easy embed and share links

Notes
- The production codebase and server run privately in Azure DevOps. This repository is for marketing/demo only and links to the live site.
